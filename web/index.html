Feasibility build

Browser-based Google authorization is available for testing. YouTube Music streaming and offline downloads are not available yet. Audio playback currently uses a local sample.

Account connection

Connect through Google.

Use your system browser to authorize read-only access to your YouTube channel and playlists. This does not create a YouTube Music browser session.

Google Cloud setup
  1. Create a Google Cloud project and enable YouTube Data API v3.
  2. Configure the Google Auth consent screen. If the project is in testing, add your Google account as a test user.
  3. Create an OAuth client with application type Desktop app. Enter its ID and secret here.

Credentials stay in Windows Credential Manager, macOS Keychain, or Linux Secret Service. If the store is unavailable, connection stops. Testing grants may expire after seven days.
