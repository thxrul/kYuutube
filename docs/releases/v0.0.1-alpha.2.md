Native Google account and local-audio diagnostic. **This is not yet a complete YouTube Music client or a Metrolist desktop port.**

### New in alpha 2
- Sign in through the system browser with your own Google **Desktop app** OAuth client, PKCE S256, state validation, and an expiring loopback callback.
- Store the client and refresh grant in Windows Credential Manager, macOS Keychain, or Linux Secret Service; no plaintext fallback. Access tokens stay in memory.
- Check your YouTube channel and read-only, paginated YouTube playlists. Refresh expired access credentials, cancel sign-in, and disconnect/revoke access.
- Included Google Cloud setup guide and a detailed Metrolist feature inventory.

### Test on Windows
Download the Windows x64 ZIP, extract it, and run `kyuutube-desktop-spike.exe`. Read the included `GOOGLE_ACCOUNT.md`. The account screen needs WebView2; libmpv and the sample environment variable are needed only for the separate audio diagnostic. Never share credentials, cookies, authorization/callback URLs, or tokens in test reports.

### Known limits
- Live Google consent and actual Windows/macOS keychain/application behavior need validation; automated account tests use fictitious credentials. Successful OAuth or a YouTube Data API query does **not** establish a YouTube Music session.
- YouTube Music search, native streaming, library sync, offline downloads, and the rest of Metrolist parity remain unfinished. Offline downloads are requested; Last.fm and Discord are excluded.
- The cloud proxy blocks the Music origin. Authenticated streaming and account entitlements remain unverified; no ad skipping or Premium bypass is implemented.
- The previous virtual Linux diagnostic exceeded the 200 MB memory target. The target has not been relaxed. Full soak/throttle/platform suites and the final design audit are still outstanding.
- Unsigned standalone executables, not installers. The archives include setup instructions, sample audio, source metadata, licenses, and checksums. libmpv is separate.

CI verifies successful build provenance and package checksums before publication, then downloads and verifies the public release assets. See the included build metadata for the exact source commit.
