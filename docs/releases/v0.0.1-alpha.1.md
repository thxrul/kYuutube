An early native local-audio feasibility preview of kYuutube.

### Downloads
- Windows x64: `.zip`
- Linux x64, macOS Apple Silicon and macOS Intel: `.tar.gz`
- `SHA256SUMS.txt` verifies the downloaded archives. Each archive also contains checksums, setup instructions, a sample WAV, and build metadata.

Extract the archive and read its `README.md` before launching. These are unsigned standalone executables, not installers. **libmpv is required separately and is not bundled.** Windows also needs WebView2; Linux needs the documented WebKitGTK dependencies.

### Current scope and limitations
- Local sample playback diagnostic with play/pause, seek, and volume controls.
- **Google sign-in, YouTube search, and YouTube streaming are not implemented or verified.** Cloud access to YouTube was blocked during feasibility testing.
- Linux native tests and UI checks passed. Windows and macOS binaries were compiled in CI; their application GUI and audio playback still need testing on those platforms.
- The 200 MB memory target is not met: best measured virtual Linux playback used about 272 MiB PSS / 469 MiB summed RSS, with 2.25% of one CPU core. No long-duration soak certification has been completed.
